
# 🎯 Product Goals & Tech Stack

## Core Objectives

* **Efficiency:** Memangkas SLA legal closing dari 14 hari menjadi 3-5 hari.
* **Integrity:** Validasi dokumen otomatis via SHA-256, e-Meterai (PERURI), & e-Sign (PSrE).
* **Automation:** Sync data pembiayaan otomatis dari CBS/LOS ke draf Notaris.

## Tech Stack Target

* **Frontend:** Vue 3 (Composition API, `<script setup>`), Pinia, Vue Router.
* **Styling:** Tailwind CSS + Headless UI / Shadcn Vue.
* **Backend:** Go (Golang) — Gin / Fiber framework.
* **Database:** PostgreSQL (v15+) + GORM / SQLx.
