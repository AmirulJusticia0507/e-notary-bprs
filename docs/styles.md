# UI Style Guide (Tailwind CSS)

## Palette Configuration (`tailwind.config.js`)

- **Primary (Navy):** `bg-slate-900` (`#0F172A`), `text-slate-900`
- **Brand Accent (Blue):** `bg-blue-600` (`#2563EB`), `hover:bg-blue-700`
- **Success:** `bg-emerald-600` (`#16A34A`), `text-emerald-700`
- **Warning/SLA:** `bg-amber-500` (`#F59E0B`), `text-amber-700`
- **Danger/Overdue:** `bg-red-600` (`#DC2626`), `text-red-700`
- **Canvas:** `bg-slate-50` (`#F8FAFC`)

## Typography & Components

- **Font:** `font-sans` (Inter / System UI).
- **Cards:** `bg-white rounded-lg border border-slate-200 shadow-sm p-5`
- **Buttons:** `px-4 py-2 rounded-md font-medium transition-colors duration-150`
